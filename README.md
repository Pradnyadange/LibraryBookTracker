📚 Library Book Tracker
A simple text-file-based Library Book Tracker for managing books, library members, borrowing records, notes, fines, opening hours, and monthly reports.

✨ Features
📖 Manage library books

👥 Maintain library member records

🕐 Store library opening hours

💰 Manage library fine policies

📝 Add notes related to books

🔍 Define book search rules

📊 Generate monthly library reports

📁 Organize generated reports in a dedicated folder

🌿 Git-based branch and version management

📂 Project Structure
LibraryBookTracker/
├── reports/          # Generated library reports
├── books.txt         # Book records
├── members.txt       # Library member records
├── library.txt       # Library opening hours/details
├── fine.txt          # Library fine policy
├── notes.txt         # Book-related notes
├── report.txt        # Monthly report information
├── search_rules.txt  # Book search rules
└── .gitignore        # Git ignore configuration

🗃️ Data Files
books.txt
Contains information about books available in the library.

members.txt
Stores registered library member information.

library.txt
Contains library information such as opening hours.

fine.txt
Defines the library's fine policy.

notes.txt
Stores notes associated with books.

search_rules.txt
Contains rules used for searching and locating books.

report.txt
Contains information used for generating monthly reports.

reports/
Stores generated report files for library activity.
